---
title: "OpenAPI Overlays"
description: "Apply safe generation hints without mutating the source OpenAPI file."
---

Overlays let you attach SDK naming and visibility hints to operations without
editing the source OpenAPI document.

```json
{
  "version": "0.1",
  "operations": {
    "GET /users": {
      "sdkName": "list",
      "resource": "users",
      "modelName": "User",
      "pagination": {
        "type": "cursor",
        "cursorParam": "cursor",
        "nextCursorField": "next_cursor"
      },
      "notes": "Use the account-scoped list operation in SDK examples."
    }
  }
}
```

Overlay fields are applied during normalization, so downstream SDK, report, and
agent tooling can consume the same operation metadata from the normalized spec.
