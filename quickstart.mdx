---
title: "Quickstart"
description: "Run local SDK surface and generation checks with synthetic fixtures."
---

Install dependencies:

```bash
bun install
```

Normalize a synthetic OpenAPI document:

```bash
bun run sdkparity spec normalize fixtures/synthetic/openapi/base.json --output normalized.json
```

Extract old and new TypeScript SDK manifests:

```bash
bun run sdkparity manifest create --language ts --repo fixtures/synthetic/ts-sdk-old --output old.json
bun run sdkparity manifest create --language ts --repo fixtures/synthetic/ts-sdk-new --output new.json
```

Extract a Python SDK manifest:

```bash
bun run sdkparity manifest create --language python --repo fixtures/synthetic/python-sdk-old --output python.json
```

Compare the SDK surfaces:

```bash
bun run sdkparity compat diff old.json new.json --format markdown
```

Generate a local TypeScript and Python evidence bundle:

```bash
bun run sdkparity run generate \
  --spec fixtures/synthetic/openapi/base.json \
  --overlay fixtures/synthetic/openapi/overlay.json \
  --languages typescript,python \
  --output-dir .tmp/sdkparity-run
```
