---
title: "Manifest Commands"
description: "Create SDK surface manifests."
---

Create a TypeScript SDK surface manifest:

```bash
bun run sdkparity manifest create --language ts --repo fixtures/synthetic/ts-sdk-old --output manifest.json
```

Create a Python SDK surface manifest:

```bash
bun run sdkparity manifest create --language python --repo fixtures/synthetic/python-sdk-old --output python-manifest.json
```
